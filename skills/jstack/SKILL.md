# Jstack router

1. Read [routes.md](references/routes.md) and [codex-compatibility.md](references/codex-compatibility.md) completely.
2. Route the request to one primary skill:
   - General rigorous task: `$poteto-mode`.
   - Current mechanics: `$how`.
   - Historical rationale: `$why`.
   - Boundary design: `$architect`.
   - Competing solutions: `$arena`.
   - Partitioned parallel work: `$swarm`.
   - Adversarial review: `$interrogate`.
   - Durable retrospective: `$reflect`.
   - Model and effort configuration: `$setup-pstack`.
3. Tell the primary skill to read its own file completely. Compose secondary skills only when the primary workflow triggers them.
4. Start with zero or one child. Expand only for an independent evidence lane, disjoint work unit, or useful competing candidate.
5. Keep integration and final judgment in the parent. Verify child evidence and every child-authored diff.

Completion means the selected skill's own completion criterion is satisfied and every additional context has a stated reason.
