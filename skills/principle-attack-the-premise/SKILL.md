# Attack the premise

When two or more fixes sharing one premise fail the same check, investigate that premise before proposing another fix that assumes it.

- Write the shared premise and the evidence that could refute it.
- For an imbalance, measure its distribution across actors with a rerunnable census. Follow [Build the Lever](../principle-build-the-lever/SKILL.md).
- If the same actors repeatedly carry the cost, trace what assigns that role. Test the assignment as a cause through [Fix Root Causes](../principle-fix-root-causes/SKILL.md).
- Compare removing or changing that assignment with compensating mechanisms. Prefer the simplest remedy supported by the measurement, within the existing task scope.

An even census weakens the actor-assignment hypothesis; it does not prove every shared assumption correct. Keep the evidence and test another mechanism. [Redesign from First Principles](../principle-redesign-from-first-principles/SKILL.md) handles a changed requirement; this principle tests an existing assumption.
