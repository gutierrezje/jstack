# Unslop

Preserve the author's meaning, voice, and technical precision. Use concrete words, active verbs, and sentences that are easy to follow. Cut filler, promotional claims, formulaic contrasts, and unnecessary formatting.

For a detailed editing pass, read [the pattern checklist](references/patterns.md). Apply the patterns that occur in the text; preserve intentional style and exact quotations. Return usable prose without narrating each correction.
