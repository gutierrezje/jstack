# No comments

1. Define scope from the caller's files or diff; otherwise use the current diff against the base branch.
2. Spawn one read-only child on the configured review route. Tell it to read `$comment-sicko` completely and return deletions, keep exceptions, and exact `MUST KILL` reshape targets. It must not edit application code.
3. Verify every finding against nearby code. Keep only legal headers, public API contracts, proven foreign constraints, required formatter directives, justified lint exceptions, and issue/RFC links that encode facts code cannot.
4. Apply accepted comment deletions and the smallest root-cause reshapes in scope. Use `$how`, `$why`, or `$architect` when a claimed constraint is not locally provable.
5. Run focused verification and report deletion count, keeps with proof, reshapes, rejected findings, and unenforced constraints.

Completion means every scoped comment is deleted, proven by an allowed exception, or reported as an unresolved constraint.
