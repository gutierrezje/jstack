# Opening a PR

1. Run only when the user authorized creating or updating a PR. Resolve base, branch, issue, and existing PR first.
2. Review the complete diff, remove slop with available cleanup skills, and run required checks.
3. Commit coherent, reviewable units using repository conventions; preserve unrelated work.
4. Push non-destructively and open/update the PR with intent, behavior, verification, risks, and reviewer guidance.
5. Read the resulting PR state and link. Start babysitting only when requested.

Completion: the remote PR matches the reviewed local head and its checks/description reflect actual evidence.
