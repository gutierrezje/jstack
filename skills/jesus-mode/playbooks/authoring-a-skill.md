# Authoring a skill

1. Use $skill-creator and $writing-for-agents before editing.
2. Establish concrete trigger examples, scope, placement, and reusable resources.
3. Write strong metadata pointers, ordered steps, and checkable completion criteria; disclose branch-specific reference.
4. Validate the package and forward-test a realistic request without leaking the intended answer.
5. Revise from observed variance and report placement, triggers, validation, and limits.

Completion: the skill validates and a cold agent follows the intended process on a representative task.
