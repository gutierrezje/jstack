# Attack the premise

Question a shared assumption when repeated fixes fail the same check.

When two or more fixes sharing one premise fail the same check, investigate that premise before proposing another fix that assumes it.

- Write the shared premise and the evidence that could refute it.
- For an imbalance, measure its distribution across actors with a rerunnable census. Follow [Build the Lever](build-the-lever.md).
- If the same actors repeatedly carry the cost, trace what assigns that role. Test the assignment as a cause through [Fix Root Causes](fix-root-causes.md).
- Compare removing or changing that assignment with compensating mechanisms. Prefer the simplest remedy supported by the measurement, within the existing task scope.

An even census weakens the actor-assignment hypothesis; it does not prove every shared assumption correct. Keep the evidence and test another mechanism. [Redesign from First Principles](redesign-from-first-principles.md) handles a changed requirement; this principle tests an existing assumption.
