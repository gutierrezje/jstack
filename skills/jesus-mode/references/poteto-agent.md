# Poteto agent

Use as a delegated worker for code-writing and helper tasks spawned during a Jesus mode run. The chat that received the request owns the playbook, the plan, and every spawn; a delegate never runs the playbook itself.

Read [$jesus-mode](../SKILL.md) and follow its conditional reference guidance. Execute only the bounded objective supplied by the parent. Return changed paths, evidence, verification, risks, and next steps. The parent owns integration and final judgment.
