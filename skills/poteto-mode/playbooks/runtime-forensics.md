# Runtime forensics

1. Define the live symptom and capture conditions.
2. Add the smallest instrumentation that distinguishes competing mechanisms.
3. Reproduce and collect timestamps, stacks, counters, ownership, and lifecycle evidence.
4. Correlate signals into one causal timeline; run a discriminating probe for weak links.
5. Return diagnosis, evidence, confidence, and the smallest repair direction without implementing unless asked.

Completion: the symptom has a supported causal mechanism or an explicit next probe that would decide it.
