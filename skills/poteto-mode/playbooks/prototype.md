# Prototype

1. State the decision the prototype must settle and the observable comparison criterion.
2. Build the smallest throwaway artifact that exposes the fork. Use two candidates for a contested design.
3. Run or show the prototypes on the real-enough surface.
4. Compare evidence, choose a direction, and record what the prototype did not prove.
5. Remove throwaway code unless the user explicitly promotes one branch.

Completion: the decision is settled by an observed result, not preference disguised as fact.
